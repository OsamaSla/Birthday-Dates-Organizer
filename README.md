# 🎂 Birthday Tracker (قائمة أعياد الميلاد)

A lightweight, responsive web application designed to help you track and manage birthdays[cite: 1]. Built using client-side HTML, CSS, and Vanilla JavaScript, featuring full Arabic language support and local browser data persistence[cite: 1].

## ✨ Features

* **Arabic UI & Custom Styling:** Built with a right-to-left (RTL) layout, Tajawal web font, dynamic gradient backgrounds, and mobile-optimized PWA settings[cite: 1].
* **Smart Monthly Grouping:** Automatically organizes birthdays by month using distinct seasonal color themes and emoji headers[cite: 1].
* **Countdown & Today's Highlights:** Calculates the exact days remaining until the next birthday, highlights birthdays occurring today with pulse animations, and displays festive confetti[cite: 1].
* **Real-time Search & Filter:** Quick search box to filter entries by name and a dropdown to inspect specific months[cite: 1].
* **Data Import & Export:** Export your birthday list to a `.json` backup file, import existing JSON files, or clear all data[cite: 1].
* **Custom PDF & Print View:** Formats the layout into a themed printable document when using the PDF export feature[cite: 1].
* **Local Storage Persistence:** Stores entries locally inside the browser's `localStorage` with initial sample data pre-loaded[cite: 1].

## 🚀 How to Use

1. Clone or download this repository.
2. Open `app.html` directly in any web browser[cite: 1].
3. Add new entries using the input form, or edit/delete existing entries directly from the list[cite: 1].

## 🛠️ Built With

* **HTML5:** Semantic markup, dynamic web manifest integration, and mobile viewport controls[cite: 1].
* **CSS3:** Flexbox layout, keyframe animations, responsive breakpoints, and print media queries[cite: 1].
* **JavaScript (ES6):** DOM manipulation, `localStorage` I/O, dynamic date calculation, and file handling[cite: 1].
